# 用户互动功能线稿图 (Wireframe)

> 目标：在不破坏现有架构的前提下，渐进式添加用户互动功能
> 原则：访客看到所有内容 → 登录后拥有个人空间

---

## 十二、技术要点备忘

1. **Prisma client 重生成**：`npx prisma generate`（改了 schema 后必须跑）
2. **SQLite 迁移**：`npx prisma migrate dev --name add-user-features`
3. **Auth payload**：从 `{ username }` 改为 `{ userId, username }`
4. **Rating 唯一约束**：`@@unique([userId, dramaId])` — Prisma 应用层检查
5. **评分防刷**：同一用户对同一剧 5 分钟内只能改 1 次评分
6. **评论分页**：初期每页 10 条，避免详情页过长
7. **观看历史去重**：同一用户对同一剧只保留一条最新记录（用 `@@unique`）
