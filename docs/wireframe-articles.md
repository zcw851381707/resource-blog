## 八、图片本地化流程

```
  微信文章 Ctrl+C 粘贴到编辑器
            │
            ▼
  ┌──────────────────────┐
  │ HTML 里图片还是       │
  │ mmbiz.qpic.cn 外链    │
  └──────┬───────────────┘
         │
         ▼  点 [📥 图片本地化] 或 保存时自动触发
  ┌──────────────────────┐
  │ 扫描 HTML 中所有 <img>│
  │ 逐张下载到服务器       │
  │ → /public/uploads/articles/xxx.jpg
  │ 替换 src 为本地路径    │
  └──────┬───────────────┘
         │
         ▼
  ┌──────────────────────┐
  │ 文章保存后：           │
  │ 图片全部在自有服务器   │
  │ 不依赖微信图床         │
  └──────────────────────┘
```

**保存时自动执行**：发布或存草稿时，自动扫描 HTML → 下载外链图片 → 替换为本地路径 → 入库

**删除时自动清理**：删除文章时，扫描 HTML 中的 `/uploads/articles/` 图片 → 从磁盘删除 → 再删数据库记录

**编辑器按钮**：也提供一个手动「📥 图片本地化」按钮，粘贴后可预览替换结果

**存储目录**：`/public/uploads/articles/`，和现有的 `/public/uploads/` 分开管理
