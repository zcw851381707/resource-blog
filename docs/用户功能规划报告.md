# 晨光曦·分享站 — 用户功能规划报告

> 当前状态：内测阶段，所有页面需登录才能访问。但登录后除了能看到内容，几乎没有任何「用户专属」的功能。用户登录缺乏价值感。

---

## 一、用户为什么要登录？——当前 vs 目标

| | 当前 | 目标 |
|---|------|------|
| 看剧 | ✅ 能看 | ✅ 能看 |
| 下载资源 | ✅ 能下 | ✅ 能下 |
| 追剧 | ❌ | 🔔 订阅追剧提醒 |
| 收藏 | ❌ | ⭐ 收藏想看的剧 |
| 历史 | ❌ | 🕐 自动记录看的剧 |
| 个性化 | ❌ | 🏠 个人首页推荐 |
| 社区 | ❌ | 💬 评论、反馈 |

**核心差距**：当前"登录"只是一道门，进去后和未登录没有任何区别。用户没有"我是这个网站的会员"的感觉。

---

## 二、登录后的专属功能规划

### ⭐ 第一优先级（立刻提供价值）

#### 1. 追剧订阅 / 更新提醒
- 用户点击「追剧中」→ 该剧加入"我的追剧列表"
- 剧集更新时，用户可以在个人中心看到「有更新」的标记
- 后续可扩展：邮件通知（已具备邮件能力）

**价值**：用户不用每天翻整个日历，一眼看到我追的剧更新了没。

#### 2. 收藏剧集
- 在剧集详情页点「收藏」→ 加入"我的收藏"
- 个人中心展示收藏列表（卡片式）
- 支持取消收藏

**价值**：用户看到想追的剧但没时间看，先收藏起来。跟"追剧"的区别：收藏是「想看」，追剧是「正在看」。

#### 3. 自动浏览记录（重做）
- 停留 >10 秒自动记录
- 个人中心「最近看过」展示最近 20 条
- 按剧集卡片展示（和前台一样的卡片）
- 15 天自动清理

**价值**：昨天看的剧今天忘了叫什么，点进来就能找到。

---

### 🔥 第二优先级（提升粘性）

#### 4. 个性化首页
登录后首页不再是固定的"最新上线"，而是：

```
┌──────────────────────────────┐
│  你正在追的剧（有更新）       │
│  [卡片] [卡片] [卡片]         │
│                              │
│  你的收藏                     │
│  [卡片] [卡片]                │
│                              │
│  最近看过                     │
│  [卡片] [卡片] [卡片]         │
│                              │
│  推荐给你的剧                 │
│  （根据你追的/收藏的推荐）     │
└──────────────────────────────┘
```

**价值**：每个人看到的首页不一样，有"这是我的专属网站"的感觉。

#### 5. 追剧日历个人版
- 日历只显示「我追的剧」，加亮标记
- 在全局日历和"只看我的"之间切换

**价值**：日历上有 20 部剧，但用户只关心自己在追的 3 部。过滤掉噪音。

#### 6. 剧集进度追踪
- 用户自己标记"我看到第几集了"
- 跟管理员的 currentEpisode 区分开
- 下次登录看日历就知道从哪集继续

**价值**：用户不用记"上次看到第几集"，网站帮他记。

---

### 💬 第三优先级（社区互动）

#### 7. 剧集评论 / 短评
- 每部剧下面可以写短评（类似豆瓣短评）
- 显示其他用户的短评
- 点赞/回复

**价值**：用户不仅仅是消费者，还能参与讨论。社区感。

#### 8. 剧集评分
- 1-5 星评分
- 显示平均分
- 个人中心展示「我评过的剧」

**价值**：帮助其他用户选剧，沉淀用户数据。

#### 9. 求资源投票
- 现在的"求资源"页面只展示已有的求剧
- 用户可以对别人的求剧投票（"我也想要"）
- 管理员看到高票的优先处理

**价值**：用户觉得自己的声音被听到。

---

### 🛠 第四优先级（锦上添花）

#### 10. 下载记录
- 记录用户点过的下载链接
- 个人中心「我的下载」方便回头找

#### 11. 深色模式偏好
- 用户选择浅色/深色模式，记住偏好
- 下次登录自动应用

#### 12. 首页布局自定义
- 用户可以选择首页先显示哪个区域（追剧 / 新剧 / 推荐）

---

## 三、技术实施建议

| 阶段 | 内容 | 新增表 | 工作量 |
|------|------|--------|--------|
| **阶段 1** | 收藏 + 追剧 | `UserFavorite`, `UserFollowing` | 3-4 小时 |
| **阶段 2** | 浏览记录（重做） | `BrowseHistory`（重新设计） | 1 小时 |
| **阶段 3** | 个性化首页 | 复用上面数据 | 2 小时 |
| **阶段 4** | 评论 + 评分 | `Comment`, `Rating` | 4 小时 |

---

## 四、总结

| 问题 | 答案 |
|------|------|
| 登录有什么用？ | 目前：几乎没用。只有"看内容"一个功能，和不登录没区别。|
| 需要增加什么？ | 追剧订阅、收藏、浏览记录、个性化首页——让用户觉得"这个网站认识我"。|
| 核心逻辑 | 从「人找内容」变成「内容找人」——用户登录后看到的是 TA 关心的剧，而不是全站一样的页面。|
| 最低成本快速见效 | 先做「收藏」+「追剧订阅」，这两个功能数据模型简单，前端改动小，立刻让登录有价值。|
