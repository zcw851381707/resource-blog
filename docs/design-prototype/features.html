改动清单（最小化）

📦 数据库（Prisma schema 新增 2 个表）

  • UserFavorite — (userId, dramaId, createdAt) — 唯一约束
  • UserFollowing — (userId, dramaId, status, progress) — status: watching / planned / completed / dropped

📄 新增页面（2 个）

  • /following — 追剧列表页（按状态 Tab 分组）
  • /favorites — 收藏页（卡片网格）

🔧 改造现有页面（3 个）

  • SiteChrome.tsx：用户下拉菜单加 3 个入口 + 头像红点
  • 剧集详情页：简介和下载之间插入互动按钮组（2 行代码）
  • /profile：个人中心 Tab 从 2 个扩到 4 个 + 顶部概览统计

🔌 新增 API（4 个）

  • POST /api/favorites — 添加/取消收藏
  • GET /api/favorites — 我的收藏列表
  • POST /api/following — 追剧状态变更（追/想看/已看完/弃剧）
  • GET /api/following — 我的追剧列表

🛡️ 不动文件（确保不破坏）

  • 首页 / 排期 / 全部剧集 / 搜索 / 资源请求 / 用户协议 — 完全不动
  • DramaCard 组件 — 不动（避免影响 5+ 个引用页面）
  • 现有 API 路由 — 不动
