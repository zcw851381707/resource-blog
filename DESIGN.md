## 自动状态流转逻辑

```
即将上映 ──(到达上映日期)──→ 新播
新播 ──(管理员手动改)──→ 排期中 或 热播
排期中 ──(管理员手动改)──→ 热播 或 已完结
热播 ──(管理员手动改)──→ 排期中 或 已完结

自动流转触发时机：
- 首页每次加载时检查
- 后台管理页面每次加载时检查
- 检查逻辑：status="即将上映" 且 expectedDate <= 今天 → 自动改为 "新播"
```
