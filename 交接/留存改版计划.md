# 留存改版计划

> 目标：让用户"取完资源就走"的现状变成"看完还想再看"。
> 原则：分阶段上线，每阶段独立可回滚，**不动现有数据/结构**。
> 文档作用：让任何接手的 AI（不管大模型/小模型）都能无缝接续。

---

## 一、改版背景与现状

### 现状问题
- 用户目标明确 → 拿资源 → 走人，**没有"理由"停留**
- 首页就是"推荐 Banner + 最新剧集"，看完列表就走
- 没有用户生成内容沉淀，没有"被记得"的感觉
- 追剧功能有但没强化，用户记不住"我在追什么"

### 改版目标（量化）
| 指标 | 现状 | 目标 |
|------|------|------|
| 平均停留时长 | X 分钟 | Y 分钟（待数据埋点后填） |
| 7 天回访率 | 待测 | 提升 30% |
| 追剧功能使用率 | 低 | 50% 用户用过 |

### 阶段 4：成就系统

#### 目标
- 让用户有"炫耀"的资本
- 把"追剧"游戏化

#### 文件改动清单

**4.1 数据库改动**

文件：`prisma/schema.prisma`

新增 2 张表：

```prisma
model Achievement {
  id          String   @id @default(uuid())
  code        String   @unique
  name        String
  description String
  icon        String   // emoji
  condition   String   // JSON 描述触发条件
  createdAt   DateTime @default(now())
}

model UserAchievement {
  id            String   @id @default(uuid())
  userId        String
  achievementId String
  unlockedAt    DateTime @default(now())
  @@unique([userId, achievementId])
}
```

**4.2 部署数据库改动**

⚠️ 不能用 `prisma db push`（会清表）！改用手动 SQL：

```bash
# 1. 本地
npx prisma db push --skip-generate  # 只生成 client，不动数据

# 2. 线上 Turso（手动 SQL）
turso db shell chenxi "
CREATE TABLE Achievement (
  id TEXT PRIMARY KEY,
  code TEXT UNIQUE NOT NULL,
  name TEXT NOT NULL,
  description TEXT NOT NULL,
  icon TEXT NOT NULL,
  condition TEXT NOT NULL,
  createdAt DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);
CREATE TABLE UserAchievement (
  id TEXT PRIMARY KEY,
  userId TEXT NOT NULL,
  achievementId TEXT NOT NULL,
  unlockedAt DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  UNIQUE(userId, achievementId)
);
"
```

## 四、每阶段实施流程（AI 操作手册）

接手 AI 请按以下流程操作：

### Step 1：读取状态

### Step 2：检查前置条件

- 阶段 5 依赖阶段 4（报告里包含成就数据）

1. 在 `src/` 目录下按文件改动清单开发

## 五、风险与回滚

每个阶段都是**独立可回滚**的：

| 阶段 | 回滚方式 |
|------|---------|
| 阶段 1-3 | 删组件即可（0 数据库改动） |
| 阶段 4 | DROP TABLE Achievement, UserAchievement |
| 阶段 5 | DROP TABLE MonthlyReport |
| 阶段 6 | DROP TABLE AnalyticsEvent |

**回滚步骤**：
```bash
# 1. 恢复上一版本代码
git checkout HEAD~1 -- src/

# 2. 删除新增的表（如果有）
turso db shell chenxi "DROP TABLE ..."

# 3. 重新构建部署
npm run build && pm2 restart chenxi
```
