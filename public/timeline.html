Bug
视频 Banner 不播放
视频渲染代码放在 if (hasImage) 分支里，视频 banner 没有 image 字段，永远走不到视频代码
根因：新增类型时条件链位置错误，提前 return 截断后续逻辑
Bug
点击声音按钮却切换页面
声音按钮和导航箭头同 z-index=20，DOM 顺序导致导航覆盖按钮，点击穿透
根因：相同 z-index 时 DOM 顺序决定堆叠，e.stopPropagation() 阻止不了 hit test
Bug
移动端轮播永久卡住
触屏 mouseEnter 触发 paused=true 后永远不触发 mouseLeave，轮播停止
根因：mouseEnter/mouseLeave 在触屏设备不可靠，需用 hover+pointer 媒体查询判断设备能力
Bug
视频回声/重声
每个 banner 渲染 4 个 video 元素（renderBanner 内 2 套布局 × 外层 2 个容器），display:none 不停止播放
根因：JSX 放在两处 = 两个独立 DOM 实例，display:none 不能可靠停止移动端音频
Bug
轮播过渡期间两个视频同时播放 — 重声
切页动画期间 prev 和 current 同时渲染，两个 video 都在播放
根因：动画过渡期间多实例共存，需对退场实例强制静音
Bug
快速切换 Banner 无响应
animatingRef 布尔锁在 600ms 动画期间直接忽略所有点击，快速连点只有第一次生效
根因：不要用布尔锁阻止用户操作，用可中断的 setTimeout 模式
Bug
轮播间隔太短，视频没看清就切走
基础间隔 5.6s → 8.6s，视频额外 +6s，setInterval 改为动态递归 setTimeout
Phase 6 6 月 9 – 10 图片定位 Bug 修复（WYSIWYG）
Bug
图片缩放超 280% 后上下拉伸变形
maxWidth 约束 + object-fit:fill 导致高缩放时比例失调
根因：竖版图在 3:1 容器中需要 height-based 缩放（非 width-based），width:auto 才能保证等比例
Bug
高缩放时点击拖拽图片跳位/错位
鼠标点一下图片就跳到错误位置，后台乱移
根因：posRef 初始化后从未更新（useRef 不会自动同步 state），handlePointerDown 读的是过期值
Bug
Frontend 竖版海报不显示（SSR 闪一下就消失）
刷新瞬间图片可见，hydration 后消失
根因：旧 buggy 拖拽行为产生了极端 imagePosition 值（如 top:-291%），图片被推出可视区
Bug
后台拖拽修复后，前台位置与后台不一致
PC 端图片显示位置和在后台调整的位置对不上
根因：前台 isAutoPortrait 有 maxWidth:65% 而后台没有 → 同一 zoom 值产生不同元素尺寸
Bug
移动端图片位置全部错乱
移动端用 object-fit:cover 无视 imagePosition，后台定位在移动端完全无效
根因：移动端 5:4 容器 ≠ 后台 3:1 容器，不能直接套用百分比。需从 imagePosition 反推焦点坐标，用 object-position 对准
Bug
横版图左边内容被 mask 隐藏，后台看不到
前台 mask 把图片左边 18% 完全隐藏，但后台预览显示完整图片（只叠加半透明遮罩），所见非所得
根因：任何 CSS 视觉变换（mask/clip/filter），前后台必须完全同步。mask 最终调整为 8% 全隐 + 8→35% 渐变
